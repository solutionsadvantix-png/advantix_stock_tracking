Why Every Odoo Business Needs This Module

Standard Odoo inventory reports often make it difficult to answer two simple, critical questions:

  • What was my exact Opening Stock Balance before a specific date?
  • Can I export a clean, grouped Excel sheet with real-time Running Balances per product?

This app solves these exact pain points by combining an optimized PostgreSQL engine with Executive-Grade Excel formatting.

Key Features & Highlights

Accurate Historical Opening Balance

Automatically calculates precise starting stock for any given period, warehouse, or location using optimized SQL queries—preventing zero-stock errors.

Product-Grouped Clean Layout

Groups movements product-by-product with dedicated Soft Steel Blue Header Cards displaying individual Opening Balances and clear separation.

Live Dynamic Excel Formulas

Exports .xlsx spreadsheets with active SUM & SUBTOTAL formulas for Total In, Total Out, and Ending Balances per product.

Multi-Level Custom Filtering

Filter by custom date ranges, specific warehouses or internal locations, product categories (including sub-categories), or lot/serial numbers.
